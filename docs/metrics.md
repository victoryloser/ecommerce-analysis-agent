# 指标口径

- 商品销售额 `sales`：状态为 `delivered` 的有效订单明细 `price` 合计，不含运费。
- 运费 `freight`：同一明细范围及金额准入规则下的 `freight_value` 合计。
- 订单数：按 `order_id` 去重。
- 延迟订单：`delivered_at > estimated_delivery_at`。
- 延迟率：延迟的已送达订单数 / 已送达订单数。
- 低分评价：`review_score <= 2`。
- 复购客户：同一 `customer_unique_id` 完成至少 2 笔已送达订单。
- 支付金额：按订单先汇总 `payment_value`，不能与多行订单明细直接关联后求和。

## 正式金额规则与历史兼容

新上传默认使用 `round2-order-exclusion-v1`：同一商品明细键出现至少两个不同的非空商品价时，该订单全部明细暂不计入商品额和运费；订单数、已确认的品类/商家身份及复购资格保留。准入资格在品类或商家筛选之前确定，因此仅筛选该订单的正常明细也不能重新计入金额。完全相同的重复行只计一次，正常多明细和拆分支付保留。

缺支付只使支付额未知。价格缺失、一个已知价格与空白并存、仅运费冲突，不自动扩展为整单排除；相关字段仍按未知处理。原始文件和候选值留存，不能从支付总额倒推出价格。

结果区分“按规则准入范围可确定”与“完整总体金额已知”。排除订单计数、准入订单计数和未知候选分别列出；所有订单都被排除时，准入范围合计为0，不表示这些订单的实际金额为0。订单详情中的 `order_freight` 仍是可确认的整单事实，`amount_eligible` 表示是否计入报表。

快照绑定规则，模型不能覆盖。历史 `p0-amount-v1` 保留原金额未知传播；新建快照才能迁移到正式规则。跨规则比较标为口径变化，同规则下金额资格退出/恢复与业务范围进入/退出、共同金额修订分别记账，不重复归因。

金额与差额使用 Decimal；环比及贡献保留精确分子分母，统一按 HALF_UP 显示两位百分比。零分母标为数学未定义，数据不足单独表示。证据保存比率成分，CSV保留比例原值而非百分比字符串。

## 联合维度

支持 `category × seller` 与 `month × category`，可计算商品销售额、运费、订单数、延迟率、平均评分和低分率。月份使用计划指定的日期字段。组合必须来自同一商品明细，不将订单内独立的品类集合与商家集合交叉配对。

`category × customer_state` 支持商品额、运费、组内去重订单数、两期比较、排名及金额贡献。省份按订单关联的客户确定，归属不明的省份保留独立分组。同一订单可能包含多个品类，跨组合汇总订单数须重新按订单去重。品类内金额贡献以该品类的金额净差额为分母。

每个组合先按订单去重，再计算订单数、评价及履约指标。一笔订单可以属于多个组合，因此父级订单数、比率和评分必须重新计算，不能将子组合相加或简单平均。评价与履约描述包含该组合商品的整单表现。

排名可在全体组合内或每个父分组内进行；最低订单数门槛使用已确认订单数和可能归属订单数判断资格。边界并列全部保留，未知候选只影响所属排名分区。品类 × 商家支持两期比较及贡献；月份 × 品类用于汇总、趋势和排名，不支持含绝对月份键的两期比较。

贡献率使用完整业务筛选范围的净变化额作为分母，不受最低订单展示门槛、Top N 或分页影响。可另列品类内净变化及贡献率，并分别查看增长或下降驱动；分母为零或未知时比例不可计算。贡献率可为负，也可超过 100%。

点击组合或在工作流中引用组合时，保留全部成员 ID、月份交集和原筛选条件。同名品类或商家仍按 ID 区分。跨快照的固定范围比较保留原组合，按原意图比较会重新选择组合；两侧选择不同时不报告同范围差额。

未定义联合维度下的支付分摊和复购指标。月度图表按品类绘制独立序列，缺失月份和未知值保留空缺，不补零。
