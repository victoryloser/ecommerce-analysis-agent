# 指标口径

- 商品销售额：状态为 `delivered` 的订单明细 `price` 合计，不含运费。
- 订单数：按 `order_id` 去重。
- 延迟订单：`delivered_at > estimated_delivery_at`。
- 延迟率：延迟的已送达订单数 / 已送达订单数。
- 低分评价：`review_score <= 2`。
- 复购客户：同一 `customer_unique_id` 完成至少 2 笔已送达订单。
- 支付金额：按订单先汇总 `payment_value`，不能与多行订单明细直接关联后求和。

## 联合维度

支持 `category × seller` 与 `month × category`，可计算商品销售额、订单数、延迟率、平均评分和低分率。月份使用计划指定的日期字段。组合必须来自同一商品明细，不将订单内独立的品类集合与商家集合交叉配对。

每个组合先按订单去重，再计算订单数、评价及履约指标。一笔订单可以属于多个组合，因此父级订单数、比率和评分必须重新计算，不能将子组合相加或简单平均。评价与履约描述包含该组合商品的整单表现。

排名可在全体组合内或每个父分组内进行；最低订单数门槛使用已确认订单数和可能归属订单数判断资格。边界并列全部保留，未知候选只影响所属排名分区。品类 × 商家支持两期比较及贡献；月份 × 品类用于汇总、趋势和排名，不支持含绝对月份键的两期比较。

贡献率使用完整业务筛选范围的净变化额作为分母，不受最低订单展示门槛、Top N 或分页影响。可另列品类内净变化及贡献率，并分别查看增长或下降驱动；分母为零或未知时比例不可计算。贡献率可为负，也可超过 100%。

点击组合或在工作流中引用组合时，保留全部成员 ID、月份交集和原筛选条件。同名品类或商家仍按 ID 区分。跨快照的固定范围比较保留原组合，按原意图比较会重新选择组合；两侧选择不同时不报告同范围差额。

未定义联合维度下的支付分摊和复购指标。月度图表按品类绘制独立序列，缺失月份和未知值保留空缺，不补零。
